# Floor 1.1 Reference Kernel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the smallest deterministic, model-independent TypeScript reference kernel required by Project 0 issue #2.

**Architecture:** Add a focused `src/reference-kernel/` layer above the existing RFC 8785/JCS canonical-addressing module. Canonical identity remains owned by `src/canonical-addressing/index.ts`; the new layer supplies typed domain contracts, append-only receipt history, pure bounded-authority evaluation, orthogonal pipeline admission, and offline conformance reporting.

**Tech Stack:** Node 22, TypeScript 7, `node:test`, existing `json-canonicalize`/`bs58` addressing stack, Python 3.12 independent canonical-addressing verifier.

## Global Constraints

- Reuse `src/canonical-addressing/index.ts` unchanged as the only Node/Edge/Receipt/Request canonicalization and hashing path.
- Keep the frozen nine canonical node kinds unchanged.
- No database, server, UI, vector store, model dependency, second canonicalizer, or product vocabulary.
- Authority evaluation receives explicit `evaluatedAt`; never use ambient time.
- `LeaseGrant` is immutable; successful use is represented by append-only `LeaseConsumption` receipts.
- Pipeline admission and epistemic disposition remain mechanically independent.
- Unsupported #3/#6/#10 coverage is reported as `unsupported`, never pass.
- Existing Witness residue behavior remains separate and unchanged.
